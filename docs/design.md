# 视觉规范

> 目标：让插件在 DSH 里“像官方的一部分”，同时在一排彩色插件图标里能被一眼认出。

![图标](assets/icon-256.png)

## 图标

- **底色**：深墨蓝渐变 `#0C1434 → #15245F → #090F26`，左上叠一层 `#4D6BFE` 冷光，右下补一层弱冷光。深色底在浅色插件列表里成立，白色描边让它在深色侧栏里也能与背景分开。
- **主体**：一条品牌蓝引用竖线（`#9FBBFF → #3F62F0`）+ 两枚冰白引号。竖线是“引用块”，引号是“被引用的原话”，合起来就是本插件的语义：引用是对象，不是一次性粘贴的文本。
- **层次**：外层 squircle 16px 圆角；内层 42×42 的玻璃卡片（白色 6% 填充 + 18% 描边）只负责把主体托起来，不额外加装饰。内层在 32px 以下会自然消失，主体仍然可读。
- **尺寸**：SVG 为唯一源文件；PNG 由浏览器渲染后 LANCZOS 缩放，提供 1024 / 512 / 256 / 128 / 64 / 32。16px 下仍保留“竖线 + 两块白”的轮廓。
- **色彩上限**：图标只用两种色相——深墨蓝底与品牌蓝主体；不引入第三色，避免在插件列表里显得花。

## 品牌色

| 角色 | 值 | 用途 |
| --- | --- | --- |
| DeepSeek 蓝 | `#4D6BFE` | 强调、选中、链接、图标冷光 |
| 深墨蓝 | `#0C1434` / `#15245F` | 图标底、Hero 背景 |
| 冰白 | `#E8EEFF` | 图标引号、深色底上的主文字 |
| 界面蓝 | `#4176E6` | DSH 浅色主题里的引用强调（沿用宿主 token） |

界面内不硬编码第二套配色：浅色/深色都走 `--dsw-alias-*`，只有图标和发布物料使用上面的固定色。

## 截图

- **Hero**：1600×900。左侧主张 + 图标 + 三个能力标签；右侧一张真实界面（引用区）。背景是深墨蓝 + 冷光 + 点阵，不用渐变光球或 3D 样机。
- **案例图**：1600×1000。顶部编号 + 标题 + 一行说明，下面 1408×792 的 16:9 真实截图；统一浅灰底、20px 圆角、单层阴影，不堆装饰。
- **采集方式**：隔离 DSH 实例（临时 `DSH_HOME`、独立端口、演示工作区）用真实模型对话；截图前统一视口 1440×900 @2x，再按 16:9 裁到正文区。侧栏与工作区名均为演示内容。
- **禁止**：拉伸截图、给截图加假窗口边框、把界面截图放进 3D 透视、在截图上压大段营销字。
